# Hermes Agent

Belum sempet gue verifikasi konvensi config file Hermes Agent secara langsung. Kemungkinan besar sama kayak agent framework lain (baca `AGENTS.md` atau system prompt config), tapi cek dokumentasi resminya dulu buat mastiin lokasi file yang bener.

## Cara Pasang (generik)

1. Copy isi [`../_core-snippet.md`](../_core-snippet.md)
2. Taro di file config/system prompt Hermes Agent kamu, sesuai konvensi yang dipake framework itu

Kalo ternyata konvensinya beda, edit file ini biar adapter selanjutnya lebih akurat. Kalo ada yang lebih familiar sama Hermes Agent, kontribusi PR diterima.
