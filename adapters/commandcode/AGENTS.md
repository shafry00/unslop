# Command Code

Command Code CLI baca `AGENTS.md` di root project, konvensi yang sama kayak OpenCode.

## Cara Pasang

1. Copy isi [`../_core-snippet.md`](../_core-snippet.md)
2. Append sebagai section baru di `AGENTS.md` project kamu

## Catatan

Command Code sering dipake headless (`cmd -p "..."`) buat task sekali-jalan tanpa banyak back-and-forth. Prioritasin bagian **Document Mode** dari protokol ini (lihat `../../DOCUMENT-MODE.md`) karena task headless lebih mirip nulis dokumen sekali jalan daripada chat interaktif. Pilar Curiosity (tanya balik) kurang applicable kalo mode-nya non-interaktif, jadi pastiin brief/prompt awal udah jelas sebelum jalanin.
