# OpenCode

OpenCode baca `AGENTS.md` di root project sebagai instruksi agent, sama kayak konvensi yang dipake banyak coding agent lain.

## Cara Pasang

1. Copy isi [`../_core-snippet.md`](../_core-snippet.md)
2. Append sebagai section baru di `AGENTS.md` project kamu (jangan timpa instruksi teknis yang udah ada)

## Catatan

Kalo `AGENTS.md` kamu udah panjang/padat, taro section ini di bagian atas atau kasih heading jelas (`## Cara Ngobrol` atau `## Nada Bicara`) biar gampang di-reference dan gak ke-buried di instruksi teknis lain.
